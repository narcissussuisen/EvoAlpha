# EvoAlpha

> 面向 A 股短线交易的多智能体自主量化投资团队与模拟交易进化平台。
> 命名沿革：同一项目三次命名——逐妖交易团队（2026-08-29 用户命名，10 万模拟盘团队代号）→ 妖板系统（yaoban-system，策略内核）→ EvoAlpha（2026-08-31 重构确立的进化体）。2026-09-09 起生产脚本与推送署名统一为 EvoAlpha。

EvoAlpha 以模拟盘为实验环境，由研究员、策略研究员、交易员、组合经理、风控员和复盘学习智能体协作，完成市场研究、策略验证、组合决策、模拟执行、风险监测和持续迭代。

## 原则

1. 模拟盘优先，所有自主投资决策先进入模拟组合。
2. 证据优先，行情、财务、估值和绩效必须可追溯。
3. 角色分离，研究、交易、组合和风控相互制衡。
4. 样本外验证，策略必须经过回测、walk-forward 和模拟盘灰度。
5. 失败可见，数据缺口、过期快照、策略失效和门禁失败不得静默掩盖。

当前采用统一入口、兼容旧路径、逐步迁移的方式。详见 EvoAlpha/docs/MIGRATION.md。
