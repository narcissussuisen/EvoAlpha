## 一、战法谱系（3 套入口 / 1 套确认）

| 入口 | 定义 | 买点 |
|---|---|---|
| **上升回档**（母战法） | **趋势向上 + 量价健康 + 洗盘时间短 + 有重要支撑 + 有主力做多**（五条件共振） | **涨幅 ≤3% 时筛出 → 分时回踩均价线 + 看承接力** |
| **趋势反包** | **"某一天阴线，第二天 K 线快速拉升包住前一天的阴线"** | 反包入观察 → **次日低点高于昨日低点** → **分时站上均价线** 试仓 |
| **仙人指路** | 上影 ≥ 昨收 2.8% 且 ≥ 实体 2 倍；C>MA60 且 MA60 上行；V>MA5；60 日涨幅 ∈(0.85,1.35) | **唯一可零歧义落地**（已给通达信公式） |

**共用确认动作 = 反包阳线**；**支撑位是唯一裁决锚**。

## 二、⭐⭐⭐ 买入判据（可编码）

```text
筛选时点：涨幅 0.7% ~ 3% 内筛出（越低越好）
追高禁令：分时直线拉升 > 3% → 放弃
等待条件：耐心等分时回落
触发买点：回踩均价线（VWAP）附近 + 有量配合 + 承接力度强
分时确认：白线（实时价）在黄线（均价线）上方；上行放量、回踩缩量
```

**辅助条件**（任一可加分）：
- **三重叠加**：板块涨价 + 个股涨价 + 符合战法形态
- **双风口**：业绩催化 + 长期成长空间
- **自带涨停潜质**（有涨停基因/题材热度）
- **五日线附近低吸**（如"在 5 日线附近就低吸了"）

## 三、⭐⭐⭐ 卖出判据（按优先级）

### 3.1 元框架
> **买入逻辑决定卖出规则**——"你买它的理由是什么，卖它的理由就是什么"

### 3.2 判据优先级
> **量能 > 均线 > 指标 > 盘口**（"**量能 + 均线即可解决 80% 的卖点问题**"）

### 3.3 每日盘口的五条

| # | 判据 |
|---|---|
| ① | **早上低开不及预期 / 弱于预期 → 走** |
| ② | **开盘冲高，10 点钟之前不板 → 走** |
| ③ | **股价冲高分时跌破均价线 → 走** |
| ④ | **分时拉升但没买量 → 有赚就走** |
| ⑤ | **涨停开板后 5 分钟未回封 → 落袋** |

### 3.4 持仓周期的三条

| # | 判据 |
|---|---|
| ⑥ | **不连板即止盈**（隔天不连板随时止盈） |
| ⑦ | **冲高 ≥7% 封不住 → 先锁部分利润** |
| ⑧ | **非主升行情下，反弹超过三天 → 先落袋**（三处独立表述一致） |

### 3.5 均线裁决（支撑/压力）

| 均线 | 含义 | 动作 |
|---|---|---|
| **5 日线** | 生命线 | 不破持股 / 破先减一半 |
| **10 日线** | 生死线 / 关键压力位 | 破则清仓；"离 10 日线很近 = 即将受压" |
| **20 日线** | **短期趋势线** | 线上=上升趋势；线下=趋势走弱（"20 日线下方不碰"） |
| **60 日线** | 中期支撑/压力 | 突破成功→空间打开；突破未果→震荡洗盘 |

**"有效跌破"定义 = 收盘价跌破 + 次日无法收回**。

### 3.6 板块维度的卖出（最完整拆解）
> ① 分时没买量 ② **同板块个股未同步拉升** ③ 分时直线跌破均价线 ④ **板块内部分化 → 主力未进攻该赛道**

## 四、⭐⭐⭐ 板块与大盘

### 4.1 板块强度三层结构
**高标打开高度 / 20 厘米制造赚钱效应 / 容量票承接大资金**

### 4.2 选板块三信号
① **钱往哪里流**（主力资金连续几天大额流入）② **有没有核心逻辑支撑**（政策/业绩爆发/产业升级）③ **业绩能不能跟上**

### 4.3 龙头三关键
① **启动强度**（最先启动最先涨停、回调抗跌、跳水逆势拉升）
② **资金认可度**（**换手率 10%-30%**、**早盘 10 点前强势封板极少炸板**）
③ **板块带动性**（涨停后带动板块批量拉升）

### 4.4 大盘规律（可回测项）
| 规律 | 内容 |
|---|---|
| **高开容易被砸** | "这招在大 A 上演 10 次有 8 次都被砸"（**80%**） |
| **大跌 + 大跌 = V 反** | 配合情绪冰点（涨跌家数 + 缩量） |
| **风格切换三信号** | **放量 + 高位科技补跌 + 全 A 等权止跌** |
| **弱势反弹只有 2-3 天** | 三处独立表述一致 |
| **指数个股背离** | 指数跌但红盘过半 → 杀跌集中在权重与前强势品种 |
| **看真实强弱用全 A 等权指数** | 剔除权重股干扰 |

### 4.5 情绪与资金工具
- **每日涨停表**：按方向分组，看各组当日红/绿 → 判断情绪流向（如"二八分化"）
- **成交额分析法**：绝对值 + 日环比 + 对比阶段高点缩水%
- **盘面拆解法**："把盘面拆开看"（分时段 + 等权指数）
- **板块下跌归因**：区分"基本面崩塌" vs "主动兑现 + 情绪共振"

## 五、⭐⭐⭐ 量能体系（独立知识期）

> **"MACD、KDJ、均线都可以被主力骗线，唯独成交量很难骗人。价格可以伪装情绪，但量能往往暴露真相。"**

| 维度 | 内容 |
|---|---|
| **怎么看** | **核心是比较**：① 纵向比（自身均量）② 横向比（位置）｜ ⚠️ **不看绝对量，看相对量** |
| **量价关系** | **健康趋势＝上涨放量+下跌缩量**；**风险背离＝上涨缩量+下跌放量** |
| **四形态** | 低位放量=机会／高位放量=风险／**缩量回调=可能有反复**／放量突破=大概率机会 |
| **四陷阱** | 高位爆量诱多／下跌放量抄底／**横盘假放量**／**缩量阴跌陷阱** |
| **底部倍量** | 低位长时间横盘 + 倍量柱 + 止跌企稳 → **吸筹 + 试盘** |
| **五维共振** | 成交量 + K 线位置 + 趋势形态 + 板块走势与阶段 + 整体情绪周期 |

## 十、对 EvoAlpha 的落地启示

1. **候选过滤器**：形态（上升回档/趋势反包）+ **题材热度/涨停基因** + 板块涨价逻辑（三重叠加）。
2. **买点规则可编码**：`涨幅 ≤3% 且分时回踩 VWAP 且有量 + 承接强` → 买入；`分时直线拉升 >3%` → 放弃。
3. **卖点规则可编码**：**量能 + 均线解决 80%**；关键均线为 **5/10/20/60 日**；破位判据 = **收盘破 + 次日不收回**。
4. **大盘择时信号可回测**：**高开 80% 被砸**、**大跌+大跌=V 反**、**风格切换三信号**、**弱势反弹 2-3 天**。
5. **不可机械化的部分**：其**执行存在人工裁量**（皖维高新案例）→ 移植时需**保留容差与人工复核**。
6. **口径需谨慎**：资金/天数/胜率声明**存在不一致**，引用时须标注来源与可信度。
