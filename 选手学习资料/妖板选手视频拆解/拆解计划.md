## 二、工作方法

### 2.1 抽帧管线（**不做 ASR**）

视频均带**烧录字幕**，抽帧即可全文取证。管线沿用已验证的流程：

```
ffmpeg 抽帧（字幕带 fps=2 + 完整帧 fps=1）
  → PIL 相邻帧去重（阈值 ~1.6）
  → 纵向拼接（每张 ≤18 条，超过会被读图降采样致字幕发虚）
  → 逐张人工读图
```

**⚠️ 本批新增难点：26 种分辨率 → 字幕位置不统一**

- 9/3-9/10 那批只有 720x720 / 866-898x720 两种版式，可硬编码裁切 `crop=iw:84:0:628`
- 本批 960x720、720x960、720x1280 等多种版式 **必须自适应定位字幕带**
- **对策**：写 `locate_subtitle.py` —— 对每个视频抽 5-8 张采样帧，逐行计算像素方差找"字幕行带"（字幕行在时间轴上会反复变化且集中在同一 y 区），自动输出裁切参数；定位失败则**回退到"完整帧"路径**（读全画面，不裁）

### 2.2 "当时的情况"核验（本计划的**核心增量**）

对每一期，除读字幕外，**必须拉当时的真实行情做交叉核验**：

| 视频类型 | 核验内容 |
|---|---|
| 每日复盘 | 当日上证指数走势 + 其提到个股的日线；标注其买入/卖出价在当日 K 线的位置；**验证自述业绩真伪**（"抓板""落袋 X%"） |
| 战法教学 | 教学案例个股的 K 线形态，验证其所述战法特征是否成立 |
| 板块策略 | 当时板块指数/龙头股走势，验证其预判是否兑现 |

工具：`tpoint/core/datasource.tdx_client`（`cli.bars` 日线 / `cli.quotes` 实时 / `cli.index_bars('999999')`）+ westock 外部核实代码。

  "**rc=0 但无产出**"硬校验 ＋ 批次循环加"单期失败不中断整批"保护。
