## 一、⭐⭐⭐ "3 个点"口径的最终澄清（07-20，**长期悬空缺口**）

背景：此前多处出现"买点在 3 个点以内"（05-12、05-27、06-23），但**从未说明其操作含义**。

> "**信通电子，早上 2 个点筛选出来，分时直线拉升超过 3 个点的，我都不会去追着玩。
> 只会耐心等待分时回落，回踩均价线后再观察资金承接力度。**"

### 完整解读

| 环节 | 规则 |
|---|---|
| **① 筛选时点** | **涨幅 2 个点**（今晨筛出）；07-06 更出现过 **0.7 个点**即筛出 → **门槛越低越好** |
| **② 追高禁令** | **分时直线拉升超过 3 个点 → 不追**（"我都不会去追着玩"） |
| **③ 等待条件** | **耐心等待分时回落** |
| **④ 触发买点** | **回踩均价线** |
| **⑤ 最终确认** | **观察资金承接力度**（承接强才买） |

⭐ **结论**：所谓"买点在 3 个点以内"**不是"涨到 3% 就买"，而是"超过 3% 就不追，等回踩均价线 + 看承接力"**。
→ **这是本库中对"3 个点"最完整的一次解释**，可直接编码为：
```python
if 当前涨幅 <= 0.03 and 分时回踩至 VWAP 附近 and 承接力度强:
    买入
elif 分时直线拉升 > 0.03:
    放弃（不追）
```
