## 1. 目标重述（一页纸）

**一句话目标**：EvoAlpha = 妖板选手**决策过程**的可执行复刻体，在一套**可审计的账本**上自主跑 A 股短线，用**它自己的前向净值**证明有效。

| 要素 | 定义 |
|---|---|
| 学什么 | 选手的**决策过程与纪律**（不是收益承诺、不是净值曲线） |
| 怎么学 | 行为克隆：离散决策标签（候选/执行/持仓/原话）→ 决策环算子 + LLM 裁量 |
| 人格 | SOP 知识库 + 决策环 + 裁量点 + 记忆 + 自述，**版本化可回滚** |
| 权限 | 模拟盘全权自主（研究→决策→组合→执行→风控→复盘闭环），无真实资金 |
| 判据 | 自身前向净值 vs **市场基准臂**（同费用模型、同时段） |
| 人类角色 | 看板监控 + 关键门禁批准；不逐单审批 |

**为什么不能用「复刻得像」当目标**（必须在计划里写死，否则系统自相矛盾）：
2026-09-11 自迭代已证伪——「分时跌破均价线 → 不玩」在 18 条明示决策上命中选手行为 **94.4%**，但扩到全市场反事实后**方向相反且高度显著**（被否决组前向 5 日 +1.093% vs 通过组 +0.471%，Welch p=0.00014；低于均价线时间占比分档单调反向）。**行为复刻 ≠ 收益来源**。因此本计划将两条命题**架构级分离**：
- **行为复刻**（人格层 + 诊断轨）：衡量"像不像"，用于人格调优，**不作晋级理由**；
- **收益验证**（主账本净值）：唯一晋级理由。

## 4. 关键机制设计

### 4.1 决策环六段（L2 核心）

每段给出：**代码硬规则**（进入 LLM 前必须成立的）｜**LLM 裁量点**（不可编码判定）｜数据依赖｜现状

| 段 | 代码硬规则（确定性） | LLM 裁量点 | 数据依赖 | 现状 |
|---|---|---|---|---|
| ① 环境闸门 | 涨停家数分档（冰点34/磨底64/普反116-124/活跃99-106）、最高连板高度、成交额环比、全 A 等权涨跌、高开幅度 | 「今天做还是不做、做到什么强度」——含选手有明确范例的**主动整体观望** | 情绪表、指数、等权 | `market_sentiment_stats.py` 有部分；闸门未成环 |
| ② 定主线 | 板块涨停梯队、板块内龙头识别、板块涨幅排名、主力净流入排序 | 「钱往哪流 / 有无核心逻辑 / 业绩能否跟上」三信号的**加权与取舍** | 板块题材库、资金流 | **缺板块题材库与资金流** |
| ③ 选真龙 | 三入口形态筛：仙人指路（**公式已零歧义**）、上升回档（五条件）、趋势反包（定义已补齐） | 「形态像不像 / 有无涨停基因与题材热度 / 是洗盘还是走坏」 | 全市场日线 | 形态算子已在 `parameters.toml` + `plan_daily.detect_huigui_v5` |
| ④ 找低吸 | 涨幅 0.7%~3% 筛出、追高禁令（分时直线拉升 >3% 放弃）、回踩 VWAP、放量确认 | 「承接力度强不强」分级（①有量+稳步向上 / ②无量欠缺力度 / ③破均价线弃） | 候选池实时 1m | 分钟覆盖仅 970 只；⚠️「破均价线」已证伪为**收益**过滤器→**只作诊断，不作拦截** |
| ⑤ 稳持仓 | 量能+均线硬规则（5/10/20/60）、破位判据=收盘破+次日不收回、10 点纪律、炸板/次高点 | 「同板块是否同步拉升 / 板块内部分化 / 主力是否未进攻该赛道」 | 持仓票 1m + 板块实时 | `src/core/sell.py` 已有引擎，**未接生产** |
| ⑥ 仓位 | 单笔亏损 ≤2% 总资金、单票 ≤30%、牛50-70/震30-50/熊≤20、底仓60-70+机动20-30+现金10-20 | 区间内档位选择 + 取舍排序 | 账户权益 | 现为静态 45%×初始本金 → **须改为动态权益预算** |

**纪律**：LLM 可以在区间内裁量，**不能创造买入理由**，不能覆盖硬规则与风控 veto（继承蓝图 §6）。

### 4.2 LLM 裁量层协议

| 项 | 约束 |
|---|---|
| 职权 | 只在**非结构化判定**出力；输出限定 schema（枚举 + 0-1 评分 + ≤N 字理由） |
| 禁止 | 自由文本下单、覆盖硬规则、绕过硬风控、生成新标的理由 |
| 落盘 | 每次调用记录：prompt 模板版本、模型名、输入数据快照 hash、输出、耗时、tokens |
| 可重放 | temperature=0 + 模板/模型版本冻结 → 给定同一快照必须复现同一输出；不可重放则判 `unreproducible` 并弃用该次裁量 |
| 限流 | 候选级调用（≤50 只/日），**不做全市场调用**；同标的同状态 5 分钟内复用缓存 |
| 降级 | LLM 不可用时回退为**硬规则 + 保守默认档**（不是回退为"不交易"以外的自由发挥） |

运行时前置：`DEEPSEEK_API_KEY` **已于 2026-08-31 配置完成**（`P0_CHANGELOG.md` P0-4，Vibe doctor 17 ok / 0 fail）→ **该项不再是阻塞项**。

### 4.3 净值判定器（替代 20 标签日门禁）

**这是"自身净值说了算"的可执行化。必须写死以防退化成"赚了就算对"。**

| 项 | 设计 |
|---|---|
| 主账本 | EvoAlpha 自主模拟盘，**单一真相源**；初始资金 25 万（对齐选手量级，待确认 §8.1） |
| 基准臂 | 同时段、同费用模型的被动账户（全 A 等权 / 中证 2000，待确认 §8.2）→ **排除 β** |
| 诊断轨 | 选手命中率 / 漏选误选 / 纪律合规率 → **只报告，不作晋级** |
| 节律 | 每 **20 交易日体检**（只出报告）；每 **60 交易日正式评审**（可暂停 / 回滚） |
| 通过条件（数值待确认） | ① 累计净值 > 基准臂；② 最大回撤 ≤10%（不触发 15% 终止）；③ 收益/回撤 优于基准臂；④ 纪律合规率 = 100% |
| 统计诚实性 | 60 交易日 ≈ 3 个月，属**单一市场状态** → 结论必须与基准臂同时报告，禁止只报绝对收益 |

> 与旧门禁的差别：旧门禁问"像不像选手"；新判定问"**扣掉市场 β 之后还剩下什么**"。前者 9/11 已被证伪为正指标，后者才对应"自主获取收益"。

### 4.4 选手标签库（学习层输入）

沿用蓝图 §5.4 四类标签，但补三条**本会话新确认的硬约束**：

1. **公开候选池 ≠ 完整交易集**（已累计 3 例跨 3 个交易日：9/8 粤传媒、9/9 诺普信、9/11 道明光学均**未公开但买入**）→ 标签库必须用**持仓截图交叉校验**，否则系统性漏掉真实交易。9/11 甚至双向偏离（池内漏买 2 只 + 池外买 1 只）。
2. **执行含人工裁量容差**（皖维高新明确"留意 7.5 支撑"、收盘 7.41 已破位、实际 06-17 才卖 → **3 个交易日偏差**）→ 人格复刻的止损必须带**容差带**，不能当严格机械策略，否则人格会与选手本人的执行系统性偏离。
3. **净值/胜率声明不可作真值**：可解析净值点仅 **28 天（38.4%）**、7 月 **44 天断裂**、本金口径在 3W/5W 间摇摆、天数出现倒退、"6 月胜率 91%"**仅出现在标题、正文未复述**。
   → **可核验的只有离散决策与单笔盈亏**（候选/持仓截图 + 18 只个股 K 线核验 17/18 命中、4 个点位全中，精度 0.6~1.6%），**没有可用的连续净值基准**。三轨评价中的"选手净值轨"必须标注为**弱证据/仅参考**。

### 4.6 「如何把选手交易模式量化」——技术路线（直接回答用户核心提问）

**四步法，且第 4 步是本计划与所有前序工作的根本区别**：

| 步 | 动作 | 已有基础 |
|---|---|---|
| ① **规则层** | 37 条规则 → 决策环六段的**可执行算子**（形态/均线/量能/环境分档） | `parameters.toml` 37 条（带证据等级 + 视频出处，**已成型**）+ `detect_huigui_v5` + `sell.py` |
| ② **裁量层** | 不可编码判定（承接强度、板块分化、洗盘 vs 走坏、涨停基因）→ **LLM 按 SOP 分级**，输出枚举 + 理由 | 无（R3 新增） |
| ③ **容差层** | 点位不写点值写**区间**：均线支撑容差 **≤2%**（9/11 K 线核验结论，比早期估计的 3~7% 更紧）；执行偏差容许（皖维案 3 日） | K 线核验报告 |
| ④ **组合层** | **不追求单条规则正 alpha**，以**组合决策**为验证单位，收益交给主账本净值判定 | 9/11 已证伪单条独立性 |

第 ④ 步的证据（同管线、同时段对照）：

| 单元 | 独立运行结果 | 结论 |
|---|---|---|
| 涨停回踩低吸 | 影子盘 **−33.7%**（113 笔，回撤 −36.8%）；出场参数 7 组网格全负 | 形态单独不成立 |
| 上升回档低吸 | 影子盘 **+22.4%**（137 笔，回撤 −13.0%） | 形态单独可正，但不足以证明是选手的边际 |
| 分时破均价线（纪律） | 命中选手 **94.4%**，全市场反事实 **显著反向** p=0.00014 | 行为特征，非 alpha 来源 |

→ **推论**：选手的超额来自**层间组合**（环境 × 板块 × 形态 × 分时），任何单层都被证伪过。因此量化路线必须是**组合决策 + 整体净值判定**，而不是继续找"那条神奇规则"（这正是前序 R1′-R7′ 的教训：R6′ 机械复刻最佳仅约 0.92x，未达 3x）。

## 7. 硬边界（明确不做的事）

1. 不把"命中选手"当晋级理由（9/11 已证伪）。
2. 不用选手公开候选改写**已发生**的决策或预测（防未来函数）。
3. 不让 LLM 绕过确定性账本、风控 veto、硬规则。
4. 不用标题/OCR 推断/后期总结冒充交割真值（E3-E6 不入训练真值）。
5. 不把"净值/胜率声明"当选手真实绩效（28/73 可解析、44 天断裂）。
6. 不并行多账本冒充净值（净值必须单一真相源）；不跨版本段拼接绩效。
7. 不接真实资金（`real_order_submission=false` 永久有效）。
8. 不删除既有计划任务（只更新 action 路径；`yaoban_tasks/root.txt` 是路径单一真相源）。
9. 不覆盖现有生产账本（v2 新建主账本；旧账本冻结为对照）。
10. 不做全市场多年分钟库（工程量不可承受且非必需，见 §4.5）。
