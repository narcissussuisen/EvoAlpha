# EvoAlpha 历史产物索引

历史产物分为有效知识、可复用研究结果、运行性缓存与日志。

| 来源 | 有效内容 | 处理方式 |
|---|---|---|
| 选手学习资料/ | 学习笔记、选手画像、交易日志、视频和图片 | 保留原入口，逐步复制索引到 learning |
| 妖板选手方法论拆解/ | 原始手册、OCR 和方法论素材 | 作为知识源档案保留 |
| yaoban-system/outputs/ | 信号、回测、walk-forward、模拟盘和迭代提案 | 有效报告按主题归档，原路径兼容 |
| 因子研究/ | 因子实验、模型拆解、代理回测和验证结果 | 保留实验环境，精选结果进入 research |
| Vibe-Research/.local/ | raw、fetch、运行账本、报告和看板快照 | 只作为私有运行数据，不混入源码迁移 |

当前未进行大规模物理移动。原因是任务计划、数据库、Parquet、虚拟环境和 .local 存在路径耦合；完成新旧入口验证后再按清单迁移和清理。
