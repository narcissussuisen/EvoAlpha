## 二、每日驱动方式（回答"怎么触发"）

### 核心原则：你不需要记任何时间

**说"例行"没有时间限制——任何时候说都行**。17:30 的晚间核验卡是保底状态流（即使你当天不开聊天框也有状态通知），与你的会话触发互不依赖。

### 证据完整度时间线（时间点只影响"看到多少"，不影响"能不能说"）

| 时点 | 发生了什么 | 此时说"例行"能看到 |
|---|---|---|
| 09:30-15:00 | 盘中交易（scan 契约运行） | 昨日完整核验 + 当日盘中快照 |
| 15:10-15:25 | close 链运行出结果 | + 当日 close exit_code |
| 15:35-16:35 | **盘后链（15:35 起跑）**：rebuild→情绪→候选→次日计划→final 验收→日志复盘 | + 链 stage 结果与次日计划 |
| **17:30** | **晚间核验卡（保底推送，合并八项）**：链/收盘/数据表/次日计划/rebuilt/验收/成交合规 | **当日全部证据齐**，最完整的核验时点 |
| 22:00（规划中） | 每日自迭代批：资料入库→知识卡片→画像→提案→影子回归 | 次日开工前看到昨日资料的结论与提案 |

**推荐习惯**：晚间 17:30 后说"例行"（证据最全 + 当日资料已收集完）。早晨说也完全可以——我核昨日证据、扫昨夜资料、继续施工，两条路径都正常工作。

### 触发词与提醒机制

你只需要记住一个词：**"例行"**。其余触发词是可选快捷方式，且**由我主动提醒你什么时候说**——里程碑达成时我在会话中直接提示，16:00 推送末尾固定带"下一步"提示行。

| 触发词 | 我执行 | 谁提醒你 |
|---|---|---|
| 例行 / 任意日常消息 | 例行序列（见下） | 不需要提醒（每天说一次即可） |
| 执行 P0 关门 | 关门四步：五日证据链核对→P0.1 重放验证→baseline-0-v1 重冻结→评审记录 | **我提示**：5 绿日齐后（预计 9/8 晚）会话中主动提示 + 16:00 推送带提示行 |
| 1A 验收 | 20 条追溯抽检+零写入审计报告 | **我提示**：1A-formal 完成后（预计 ~9/11） |
| 1B 上线 | 双榜冻结上线+总观察时钟启动 | **我提示**：1B 施工验收通过后（预计 ~9/18-21） |
| 处理 review | 组装 review_queue 预组装证据包 | **推送提示**：9/11 起 ingest 管线每日推送"今日 M 条待裁决" |

| 里程碑 | 预计时点 | 你的动作 |

| P0 关门 | 9/8（二）晚 | 对我说"执行 P0 关门"（我会先提示） |

### 每日会话例行序列（L-A 自动执行，无需你逐项指令）

```
1. 窗口/证据核对（按当前时点可得的最新证据，未出的标注"待补"）
2. 新资料扫描：聊天框当日已收文字/图片（会话内直接处理+落盘归档）+ 对比 source manifest SHA-256 清单 → 识别 选手学习资料/ 磁盘新增文件 → 解析
3. 施工推进：按 task list + 计划文件推进下一批次（无新指令时默认继续）
4. 飞书推送当日状态摘要（hook f85cb8ae）
```

**不需要**你每天想"该让我干什么"——例行序列是我的责任，你只裁决和提供资料。

## 三、资料格式约定（回答"怎么给"）

### 你要做的（每日，约 1-2 分钟）

**文字和图片直接发到聊天框**（2026-09-02 用户指定，主通道），格式宽松即可（管线柔性接入，缺什么标什么）。我收到后解析，并**自动落盘归档**（保持 `选手学习资料/` 目录结构与 manifest 扫描兼容）：

| 资料类型 | 怎么给 | 我怎么处理 |
|---|---|---|
| **文字**（帖子/聊天记录/要点） | **聊天框直接粘贴或发文件**，多条随意 | 会话中直接读取解析 → 归档为 `文字资料/YYYY-MM-DD_HHMM_主题/record.md`（格式参照既有日期文件夹） |
| **截图**（持仓页/候选页） | **聊天框直接发图**（PNG/JPG 任意） | **多模态直接看图**（我能读图），提取持仓/候选/净值 → 归档到该日文件夹 `images/` |
| **视频** | 仍走磁盘：丢 `选手学习资料/` 根目录（命名约定见下） | 见下方视频专节（聊天框不适合发视频） |

### 视频命名约定（用户 2026-09-01 23:28 指定，标签 time 字段的精度依据）

| 视频类型 | 文件名含时分秒？ | 标签 time 字段 |
|---|---|---|
| **盘中视频**（当日操作/抓板实况） | **有**（如 `2026-09-01 11-37-38 ...mp4`） | `precision=minute, basis=filename_hhmmss`——文件名时间戳=发布时刻，画面内容=该时点状态 |
| **复盘视频**（收盘后总结/板块分析） | 无（只有日期，如 `2026-09-01 收获九月开门红...mp4`） | `precision=day`——内容为收盘后回顾，盘中具体时点不可考 |
| 教学视频（战法讲解类） | 通常无 | `precision=day`，method_claim 素材为主 |

**解析含义**：盘中视频的持仓快照 = **发布时刻的盘中状态**（不是收盘态）；复盘视频的快照 = 收盘态或盘中回放（需结合画面判断）。两类不混用。

### 不需要做的

- ~~不用把文件发到聊天框~~ → **2026-09-02 起反转：文字/图片优先发聊天框**，我负责落盘归档；磁盘目录投递仍兼容（例行 manifest 扫描照常兜底，两条通道不冲突）
- **不用等我问**——每日例行序列自动扫描新增（对比 manifest）
- **不用整理到完美**——缺字段/格式乱 → 进 review_queue 标注缺什么，不会拒绝

### 视频专节（诚实边界）

我**不能直接"看"视频文件**。三条处理路径按优先级：

1. **日常主路径（推荐）**：每日视频的核心信息=候选+持仓+操作，这些**文字+截图就完整覆盖**（8/31 日志样本已实证：MD+PNG 完整还原视频内容）。所以日常只需文字+截图，视频作为存档低优先级处理。
2. **存量 72 个视频**：OCR 产物已在（4,100 帧含置信度）——我解析结构化文本即可，无需重跑。
3. **新视频批量处理**：批次 3 的 ASR（faster-whisper，周末安装）+ OCR 环境修复后管线化；若你想要某支视频当天出内容，**截几张关键帧丢 images/ 我直接看**，这是最快路径。
