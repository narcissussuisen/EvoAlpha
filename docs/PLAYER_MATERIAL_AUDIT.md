## 二、🔴 遗漏一：`v4_materials/` —— 权威源被误判为「已被取代」

### 事实

`yaoban-system/config/parameters.toml` 第 3 行写着：

```
# 单一事实源：所有规则参数来自《妖板选手_完整交易系统_v4.0.md》附录 B
```

而 `evoalpha_all/妖板选手方法论拆解/v4_materials/` 正是这份手册的**五册正文**：

| 分册 | 大小 | 语义对应决策环段 |
|---|---|---|
| `A_情绪周期与市场环境.md` | 40 KB | ① 环境闸门 |
| `B_每日工作流SOP.md` | 31 KB | 时间轴 + ① |
| `C_板块主线与选股.md` | 58 KB | ② 定主线 + ③ 选真龙 |
| `D_战法与进场执行.md` | 33 KB | ③ + ④ 找低吸 |
| `E_出场持有做T洗盘.md` | 39 KB | ⑤ 稳持仓 + ⑥ 仓位 |
| **合计** | **201 KB** | 与「决策环六段」几乎一一对应 |

### 为什么它是「被误判」

`evoalpha_all/MANIFEST.md` 的外迁理由写的是：

> 「81% 是 3 个 Python venv；真正有效产出仅约 7 MB；**且已被新版拆解取代**（82/82 期完成）」

**复核结论：三个分句里前两个成立，「已被取代」不成立。**
- ✅ 体积判断正确：`ocrenv` 225MB + `ocrenv2` 327MB + `videoenv` 219MB = 771 MB 是 venv，确实该外迁。
- ❌ **「已被取代」不成立**：两者**粒度不同、互补而非替代**——
  - 新版拆解（`选手学习资料/妖板选手视频拆解/`）= **48 个主题化目录的精读**，产出 5–25 KB/篇的 `record.md`
  - `v4_materials` = 基于 **72 支视频 OCR 逐字稿**的结构化提取，**每条结论都带 `v##@mm:ss` 出处 + OCR 原文 + `[OCR疑似]` 标注**
  - 例（`B_每日工作流SOP.md` 开头）：
    > `早上7点`：起床看全球新闻了解实事政策 ｜ 原文：`每关早上7点起床看全球新闻了解实事政策` `[OCR疑似:每天]` ｜ 来源：`v42@00:16`

### 影响

R1.1 的 141 条规则**完全未引用 `v4_materials`**。这 201 KB 里可能还有第 2 类遗漏没有暴露出来的规则。
**这是目前 R1 已知最大的未消化素材。**

### 建议

- **R1.1b**（新增子项）：逐册消化 `v4_materials`，与现有 141 条做**差集**，差集即待补规则；
  因其自带 `v##@mm:ss` 出处，可直接合并进 `sop_v0.toml` 的 `src` 字段，**不破坏溯源体系**。
- **同时修正 `MANIFEST.md` 的「已被取代」表述**（避免后续会话继续误信）。

> ✅ **2026-09-12 已执行**：
> - `MANIFEST.md` 的错误表述已加审计更正块修正；
> - R1.1b 已完成 → 报告 **`docs/V4_MATERIALS_DIGEST.md`**：SOP **141 → 150 条**（新增 9 条 + 扩展 7 处）；
>   v4_materials 覆盖的 70 个 vNN 中 **50 个已进 SOP**，剩余 20 个全为执行/播报类（归 R1.4 记忆层 / R3.3 标签库）；
>   **已无任何一节完全未被 SOP 覆盖**。
